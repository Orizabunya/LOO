# ลูแปล

ตัวแปลงภาษาไทย ↔ ภาษาลู รุ่นเบต้า ทำงานบนเบราว์เซอร์ของผู้ใช้ทั้งหมด ข้อความไม่ถูกส่งไปเซิร์ฟเวอร์

## มีอะไรบ้าง

- แปลงไทย → ลู และถอดลู → ไทย พร้อมปุ่มสลับทิศ
- แยกทีละพยางค์ให้เห็นว่าแต่ละคำแปลงอย่างไร
- ปุ่มคัดลอก ฟังเสียง (ใช้เสียงภาษาไทยของเครื่อง) และแจ้งแปลงผิด
- ดีไซน์ตามระบบ CloudPulse รองรับโหมดมืด

## โครงไฟล์

```
index.html              หน้าเว็บ
src/loo-engine.js       เอนจินแปลง (ใช้ซ้ำในส่วนขยายเบราว์เซอร์ได้)
tests/engine.test.mjs   ชุดทดสอบคำ
RULES.md                กฎกลางของภาษาลู
package.json            บอก Node ว่าเป็นโมดูล (ใช้ตอนรันเทสต์)
```

## เผยแพร่บน GitHub Pages (ทำครั้งแรก)

1. สมัครหรือเข้าสู่ระบบที่ github.com
2. กด **New repository** ตั้งชื่อ `loo-translator` เลือก **Public** แล้วกด Create
3. ในหน้า repo กด **Add file → Upload files** ลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ลงไป (ให้ `index.html` อยู่ชั้นนอกสุด) แล้วกด **Commit changes**
4. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
5. รอ 1–2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/loo-translator/`

### ให้ปุ่ม "แปลงผิด" ส่งรายงานเข้า GitHub

เปิด `index.html` หาบรรทัด

```js
const REPO_URL = '';
```

ใส่ลิงก์ repo ของคุณ เช่น `'https://github.com/ชื่อผู้ใช้/loo-translator'` ผู้ใช้จะถูกพาไปหน้าเปิด Issue ที่กรอกรายละเอียดไว้ให้แล้ว (ผู้แจ้งต้องมีบัญชี GitHub) ถ้าเว้นว่าง ปุ่มจะให้คัดลอกรายงานแทน

แนะนำให้สร้าง label ชื่อ `แปลงผิด` ใน **Issues → Labels** ด้วย

## ทดสอบบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```bash
node tests/engine.test.mjs
```

ดูหน้าเว็บบนเครื่อง ต้องเปิดผ่านเซิร์ฟเวอร์ (ดับเบิลคลิกไฟล์ตรงๆ จะโหลดเอนจินไม่ได้)

```bash
npx serve .
# หรือ
python3 -m http.server 8000
```

เมื่อแก้กฎหรือพบคำที่แปลงผิด ให้เพิ่มคำนั้นใน `CASES` ของ `tests/engine.test.mjs` ก่อน แล้วค่อยแก้เอนจินจนเทสต์ผ่าน

## ข้อจำกัดที่รู้แล้ว

- คำที่อ่านไม่ตรงตามรูปเขียน (เช่น สวัสดี ขนม ภรรยา) ต้องอยู่ในรายการ `DEFAULT_EXCEPTIONS` ใน `src/loo-engine.js` ถ้าไม่มี อาจแบ่งพยางค์ผิด
- ถอดลู → ไทยของคำที่มีอักษรนำอาจได้คำเขียนตามเสียง เช่น ได้ "สะหมุด" แทน "สมุด" ถ้าคำนั้นไม่อยู่ในรายการ
- ไม้ยมก (ๆ) ถอดกลับเป็นคำซ้ำ เช่น "มากมาก"
- เสียงอ่านขึ้นกับเครื่อง บางเครื่องไม่มีเสียงภาษาไทย
- GitHub Pages ใช้ได้ฟรีกับ repo สาธารณะ และไม่อนุญาตให้ใช้เป็นบริการเชิงพาณิชย์ เมื่อถึงรุ่นที่มีสมาชิกเสียเงินต้องย้ายโฮสต์
